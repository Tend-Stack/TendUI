# TendUI 2026.2.0-preview.2

This preview corrects the release consumer version check from preview.1, whose
release publication was blocked by a stale test expectation. The earlier tag is
retained unchanged. This is not a stable API commitment. It includes the TendUI module and shared SiteHeader component.

```sh
go get github.com/Tend-Stack/TendUI/v2026@v2026.2.0-preview.2
```

## Included

- 37 templ components, 24 inline SVG icons, semantic CSS and 13 demo areas.
- Styles embedded in Go binaries; standalone CSS works with any HTML stack.
- Shared responsive header, configurable appearance, native workflows and bounded CSS motion.
- Complete Go/templ and plain HTML quickstarts; see [onboarding](../quickstart.md).
- Go 1.26 minimum, templ v0.3.1100 runtime, no Node/npm or bundled browser JavaScript.

## Verification and limits

Before tagging, require the native Go/OS matrix, security scan, browser suite,
generated-source check, recipe compilation and isolated consumer packaging proof.
The consumer check also compiles and tests the onboarding example outside the
library module. After tagging, verify installation from GitHub at the exact tag.
Record the exact commits and CI links in the GitHub prerelease notes.

Automated browser checks include keyboard, reduced motion and accessibility
rules; manual screen-reader and physical-device testing remain outstanding.
One WebKit forced-color emulation case is unsupported and skipped.

See [integration guidance](../tendui-migration.md) for imports, stylesheet
setup, CSS tokens and preference cookies.
