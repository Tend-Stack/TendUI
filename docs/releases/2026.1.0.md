# GothUI 2026.1.0

The first GothUI release provides semantic CSS and 36 typed templ components,
embedded directly in a Go binary. It includes 24 inline SVG icons, configurable
appearance, native form and navigation patterns, bounded CSS motion, and
full-page/fragment HTTP helpers.

## Install

```sh
go get github.com/Tend-Stack/GothUI/v2026@v2026.1.0
```

Go 1.26 or newer is required. Components use templ v0.3.1100; generated Go is
included. The asset and rendering packages use only the standard library.
There is no Node/npm requirement for building an application, no external
asset compilation, and no bundled client-side JavaScript or HTMX runtime.

Repository access follows GitHub visibility. Private installations require
normal GitHub credentials and `GOPRIVATE=github.com/Tend-Stack/GothUI`.

## Validation and scope

Publication requires native Linux/macOS/Windows checks on Go 1.26.0 and 1.27.3,
the vulnerability scan, and the Chromium/Firefox/WebKit browser suite at the
exact tagged commit. A separate consumer installs the actual GitHub tag and
tests rendering and embedded CSS without a local replacement or a generator
before these notes are published.

Browser coverage includes native forms with scripts disabled, component-page
accessibility rules in both themes, narrow layouts, keyboard interactions,
reduced motion, print, and an isolated HTMX consumer. WebKit forced-color
emulation is unsupported and explicitly skipped. Automated rules and engine
tests do not certify accessibility conformance, all screen-reader behavior,
or physical-device compatibility; review assembled applications with their
target devices and assistive technologies.

Applications own routing, authentication, persistence, request protection, and
any HTMX runtime. Native overlay commands require browser support; the examples
include ordinary-page fallbacks. `examples/site` is reusable demonstration code,
not part of the stable component API. Versions use `YEAR.RELEASE.FIX` and the
2026 module line uses `/v2026`.
